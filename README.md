## Proyecto destacado

### [docamar.com](https://docamar.com): web del Bar Docamar
Web en producción para un negocio real, con panel de administración propio.

- Web estática (HTML, CSS y JavaScript) desplegada en **Netlify**, en español e inglés
- **Panel de administración** para que el bar actualice el menú del día, los eventos y los avisos sin tocar código
- Backend serverless con **Netlify Functions** y almacenamiento en **Netlify Blobs**
  (migrado desde Supabase), con usuarios, registro de cambios y copias de seguridad
- SEO: sitemap, redirecciones desde el antiguo WordPress y páginas de aterrizaje
- Cabeceras de seguridad y caché, e imágenes y PDFs optimizados
